# Security Policy

Website QA Auditor is a public portfolio demo for basic website quality checks.
Do not use it to test private, internal, or access-controlled websites.

## Reporting

Please report suspected security issues privately by email:

- rolly.calma.0217@gmail.com

Include the affected command, URL type, what you expected, what happened, and
reproduction steps if possible.

## Scope

In scope:

- Source code in this repository
- Documented CLI behavior
- GitHub Actions workflows in this repository

Out of scope:

- Third-party websites audited with the tool
- Network abuse, denial-of-service, or high-volume scanning
- Issues requiring access to private accounts or credentials

Please use the auditor only on sites you own, administer, or have permission to
test.
